# Netflix Exploratory Data Analysis (EDA)

## 1. Project Overview
This project focuses on analyzing the Netflix Movies and TV Shows dataset using Python.

## 2. Problem Statement
To identify trends and patterns in Netflix content through exploratory data analysis and visualization.

## 3. Dataset
Netflix Movies and TV Shows Dataset.

## 4. Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## 5. Analysis Performed
- Dataset exploration
- Missing value analysis
- Duplicate checking
- Summary statistics
- Movie and TV Show distribution
- Country-wise content analysis
- Release-year trends
- Correlation analysis
- Content rating analysis
- Genre analysis
- Movie duration analysis

## 6. Results
Visualizations were created to understand Netflix content distribution, genres, ratings and release trends.

## 7. Conclusion
The project provided practical experience in exploratory data analysis and data visualization using Python.
